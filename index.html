Authentication
Public endpoint'ler (health, swagger, public profil, NFC) auth gerektirmez. Admin endpoint'leri için X-API-KEY header'ı zorunludur.
İstek örneği
# Header ile API key gönderme
curl -X GET \
  https://dijimago-enterprise-backend.onrender.com/api/leads \
  -H 'X-API-KEY: your-api-key' \
  -H 'Content-Type: application/json'
Yanıt formatı (tüm endpoint'ler)
{
  "success": true,
  "message": "İşlem açıklaması",
  "data": { /* endpoint'e özel veri */ }
}

Event Collector Events
40+ event tipi destekleyen first-party engagement data platformu. KVKK uyumlu, AI skorlama ile zenginleştirilmiş.
POST /api/events/collect Tekil event gönder ▼
Request body
AlanTipAçıklama
tenantId zorunlustringOrganizasyon kimliği
eventName zorunlustringEvent tipi (bkz: desteklenen eventler)
consentGiven zorunlubooleanKişisel veri eventi için true zorunlu
source opsiyonelstringdijimago_profile, dijimago_web, external...
properties opsiyonelobjectSerbest key-value metadata
Desteklenen event kategorileri
// Digital Identity
profile_viewed, qr_scanned, nfc_tapped, profile_shared

// Lead
lead_form_submitted, lead_form_started, lead_form_abandoned

// CRM
crm_lead_created, crm_task_created, crm_meeting_scheduled

// Payment
payment_link_clicked, payment_completed, payment_failed

// E-Commerce
ecommerce_cart_created, ecommerce_order_completed, ecommerce_cart_abandoned

// Dealer
dealer_payment_started, dealer_risk_flagged, dealer_limit_exceeded

// AI
ai_score_generated, ai_recommendation_created
Yanıt (lead_form_submitted için otomatik lead oluşturulur)
{
  "eventId": "uuid",
  "aiScoreHint": "hot",   // hot | warm | cold | converted | at_risk
  "linkedLeadId": "uuid",  // otomatik lead oluşturulduysa
  "isKnownSchema": true
}
201 Created400 Consent Required
