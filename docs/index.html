KVKK / Consent KVKK
KVKK Madde 7 uyumlu rıza yönetimi, veri silme ve anonimleştirme.
⚖
KVKK Madde 7 — Veri Saklama ve İmha
Veri silme (delete) geri alınamaz. Anonimleştirme (anonymize) tercih edilebilir bir alternatiftir; istatistiksel veriler korunurken kişisel bilgiler anonim hale getirilir. Her iki işlem de audit log'a otomatik kaydedilmelidir.
POST/api/consentsOnay kaydet▼
İstek
{
  "subjectId": "kullanici@email.com",
  "consentType": "kvkk",   // kvkk | marketing | analytics
  "isGranted": true
}
IP adresi ve User-Agent otomatik kaydedilir.
201 Created
GET/api/consents/{subjectId}Onayları sorgula▼
200 OK
POST/api/data-retention/deleteVeri sil — Madde 7▼
İstek
{ "subjectEmail": "kullanici@email.com" }
200 OK
POST/api/data-retention/anonymizeAnonimleştir — Madde 7▼
Ad, email, telefon anonim hale getirilir. İstatistiksel veriler korunur.
200 OK
